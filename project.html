Project — Long Way Home

2D Side-Scrolling Platformer | Unity 2D | Android Demo

Long Way Home เป็นเกมเดโมที่ผู้เล่นรับบทเป็นสุนัขที่พลัดหลง และออกเดินทางผ่านป่ากับถ้ำเพื่อกลับไปหาเจ้าของ ระหว่างทางผู้เล่นจะได้สำรวจ ต่อสู้ และพูดคุยกับตัวละครเพื่อทำภารกิจ

ภาพปกเกม Long Way Home

การเล่นและระบบในเดโม

  • สำรวจฉากด้วยปุ่มควบคุมบนหน้าจอ ทั้งการเดิน กระโดด วิ่ง และโจมตี
  • พูดคุยกับ NPC รับภารกิจ และเก็บไอเท็มระหว่างการเดินทาง
  • มีระบบพลังชีวิต จุด Checkpoint และบันทึกความคืบหน้าของเกม

วิดีโอสาธิตเกม

คลิกเพื่อดูคลิปสาธิตเกม (22 วินาที)

Project — Interactive Wall

เรื่องสัตว์ทะเลอยู่ไหน? | MAT102 Group Project

โปรเจกต์กลุ่มต้นแบบผนังภาพโต้ตอบธีมใต้ทะเล ผู้ชมแหวกสาหร่ายเพื่อค้นหาสัตว์ทะเลที่ซ่อนอยู่ และดูข้อมูลสั้น ๆ ของสัตว์ที่พบ

ภาพการสาธิตโปรเจกต์ Interactive Wall

แนวคิดและการทำงาน

  • ฉายภาพโลกใต้ทะเลให้ผู้ชมสำรวจและค้นหาสัตว์ทะเล
  • ใช้เซนเซอร์ร่วมกับ Arduino รับการโต้ตอบ และเชื่อมกับภาพที่สร้างใน Unity
  • เมื่อพบสัตว์ทะเล จะแสดงข้อมูลสั้น ๆ ให้ผู้ชมได้เรียนรู้
ดูวิดีโอสาธิตบน YouTube

ภาพภายใน Interactive Art Gallery

สิ่งที่มีในโปรเจกต์

  • เดินชมงานศิลปะและเปิดดูข้อมูลของผลงานที่จัดแสดง

  • มีตู้ปลาและตัวละคร NPC ช่วยเพิ่มบรรยากาศภายในแกลเลอรี
